# 공유 접속 비밀번호 검증 (2026-10-12)

범위: 기존 `feat/agent`, 기준 `3553b88`. 사용자가 승인한 앱 공유 비밀번호로 홈·기존 API를 보호합니다. 실제 비밀값·환경 파일은 읽거나 기록하지 않았습니다.

## 구현

- 서버 전용 `FACTLENS_ACCESS_PASSWORD` 4~256자와 기존 32자 이상 `FACTLENS_BACKEND_SECRET`으로 접속 쿠키를 서명합니다. 비밀번호는 쿠키·응답·로그에 포함하지 않습니다.
- 홈·검증 GET/POST·의도·요약·JEV·대화 프록시가 본문 처리·외부 호출 전에 인증합니다. 공개·프로덕션의 미설정은 503, 미인증·위조·만료는 401입니다.
- 로그인은 동일 출처 POST·최대 4KiB·5초 본문 읽기, 단일 비밀번호 필드를 요구합니다. 24시간 `HttpOnly`·`SameSite=Lax`·HTTPS `Secure`·호스트 전용 쿠키를 발급하며 로그아웃은 해당 쿠키만 삭제합니다.
- 비밀번호·서명 키 변경은 이전 접속 쿠키를 무효화합니다. 기존 대화 소유권·동의와 Render 공유 헤더는 유지합니다. 약관·개인정보 페이지는 공개합니다.

## 최신 main 통합 확인

PR 생성 시 main이 `ae7b046`(PR #4)으로 갱신되어 기존 `feat/agent`에 충돌 없이 통합했습니다. 사용자 프론트·백엔드 변경을 보존했으며, 통합 상태에서 FE 140개·BE 458개(11.31초)가 통과했습니다. GitHub CI 실행 `38219123457`에서도 최신 main을 합친 PR의 FE 테스트·타입·빌드와 BE 잠금 의존성·전체 테스트가 모두 통과했습니다.

로컬 재빌드는 처음 Windows `spawn EPERM`으로 중단되어 권한을 보완했습니다. 이후 다른 작업에서 체크아웃이 main으로 전환되어 새 파일이 없는 `ENOENT`와 생성된 타입의 모듈 누락이 발생했습니다. 이 실행은 통합 빌드 성공으로 집계하지 않습니다. 현재 main 체크아웃을 유지하고, 안전하게 커밋된 PR과 CI를 기준으로 확인합니다. 잘못된 체크아웃에서 만든 그래프 변경은 해당 생성 파일만 복원했습니다.
