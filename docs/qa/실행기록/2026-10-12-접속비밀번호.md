# 공유 접속 비밀번호 검증 (2026-10-12)

범위: 기존 `feat/agent`, 기준 `3553b88`. 사용자가 승인한 앱 공유 비밀번호로 홈·기존 API를 보호합니다. 실제 비밀값·환경 파일은 읽거나 기록하지 않았습니다.

## 구현

- 서버 전용 `FACTLENS_ACCESS_PASSWORD` 12~256자와 기존 32자 이상 `FACTLENS_BACKEND_SECRET`으로 접속 쿠키를 서명합니다. 비밀번호는 쿠키·응답·로그에 포함하지 않습니다.
- 홈·검증 GET/POST·의도·요약·JEV·대화 프록시가 본문 처리·외부 호출 전에 인증합니다. 공개·프로덕션의 미설정은 503, 미인증·위조·만료는 401입니다.
- 로그인은 동일 출처 POST·최대 4KiB·5초 본문 읽기, 단일 비밀번호 필드를 요구합니다. 24시간 `HttpOnly`·`SameSite=Lax`·HTTPS `Secure`·호스트 전용 쿠키를 발급하며 로그아웃은 해당 쿠키만 삭제합니다.
- 비밀번호·서명 키 변경은 이전 접속 쿠키를 무효화합니다. 기존 대화 소유권·동의와 Render 공유 헤더는 유지합니다. 약관·개인정보 페이지는 공개합니다.
