# 2026-10-10 인라인 출처 번호 표기 및 존댓말 어조 개선 실행기록

## 작업 개요
- 본문 텍스트 내 원시 출처 ID 표기(`s1`, `s2`, `S1`, `S2`, `[s1]`, `[1]`, `[2]` 등)를 숫자형 인라인 출처 배지(`[1]`, `[2]`)로 렌더링하고, 호버 시 출처 제목 및 발행처 툴팁을 표시하며, 링크가 있을 경우 새 탭 연결 지원.
- LLM 검증(`backend/verification.py`) 및 요약(`backend/summarize.py`) 프롬프트 지침을 한국어 정중체(`~합니다`, `~입니다`, `~않습니다`)로 변경하고, 본문 인용 시 `[1]`, `[2]` 형태의 번호형 인용을 사용하도록 명시.

## 변경 내역
1. **프론트엔드 출처 인라인 파싱 및 렌더링:**
   - `app/lib/source-annotation.ts`: 출처 패턴 정규식(`/(?:\[[sS]?(\d+)\]|\b[sS](\d+)\b)/g`) 및 출처 ID/인덱스 매칭 유틸 함수 `findMatchingSource` 구현.
   - `app/components/source-annotated-text.tsx`: 본문 텍스트에서 출처를 감지하여 `[1]`, `[2]` 배지로 변환하고 마우스 호버 시 출처 제목(`title`) 표시, 링크 존재 시 새 탭 이동 제공.
   - `app/components/fact-check-dashboard.tsx`: `AnswerBlockView`, `JudgmentReply` (확인된 내용, 남은 불확실성, 주의사항), `ProgressReply`의 1차 요약, 대시보드의 `selected.summary`에 `SourceAnnotatedText` 적용.
   - `app/globals.css`: 인라인 출처 칩 스타일(`.inline-citation`, 호버 효과, 텍스트 커서 스타일 등) 추가.
2. **백엔드 프롬프트 지침 강화:**
   - `backend/verification.py`: `verify_claims` 프롬프트에 `~합니다`, `~입니다`, `~않습니다` 종결어미 엄격 준수(`~한다`, `~이다`, `~않는다` 금지) 및 `[1]`, `[2]` 번호형 출처 인용 지침 추가.
   - `backend/summarize.py`: `_SUMMARY_INSTRUCTIONS`에 한국어 정중체(`~합니다`, `~입니다`, `~않습니다`) 지침 추가.
3. **단위 테스트 추가:**
   - `app/components/source-annotated-text.test.mjs`: `findMatchingSource`의 ID 접두사 매칭, 1-based 인덱스 폴백, 미확인 출처 안전 처리 및 한국어 조사 앞 `s1`, `S2`, `[1]`, `[s2]` 정규식 감지 검증 4개 테스트 추가.
