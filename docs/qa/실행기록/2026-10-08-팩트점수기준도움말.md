# 2026-10-08 [bsj] 팩트 점수 기준 도움말

## 변경 내용

- 주장별 팩트 점수 옆에 `점수 기준` 버튼을 추가했습니다.
- 버튼에 마우스를 올리거나 키보드 포커스를 두면 5단계 기준표가 열리고, 해당 점수가 속한 구간을 강조합니다.
- 표의 글자와 배경 대비를 높였으며, 좁은 화면에서는 점수 영역을 세로로 배치합니다.
- 점수가 사실일 확률이 아니며 평균 점수가 원문 전체의 사실 여부를 뜻하지 않는다는 안내를 넣었습니다.

## 실행 및 검증 기록

| 확인 | 결과 |
|---|---|
| Serena 정적 참조 확인 | 5개 구간이 기존 `scoreBand` 범위와 일치하고, 점수 구간 강조 및 주장별 점수 옆 버튼 렌더를 확인함 |

| `git status --short --branch` 및 `git diff --check` | 실행을 시도했으나 실행 프로세스 생성 실패: `helper_unknown_error: setup refresh had errors` |
