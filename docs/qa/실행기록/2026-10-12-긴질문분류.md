# 긴 검증 요청의 대체 분류 처리

## 변경 내용

의도 분류 API가 응답하지 않을 때 로컬 분류기가 60자를 넘는 요청을 모두 확인 질문으로 처리하던 문제를 수정했습니다. “사실인지”, “맞는지”, “거짓인지”, “팩트체크”처럼 의도가 분명한 입력은 길이와 첨부 여부에 관계없이 검증 흐름으로 넘깁니다. “그거 맞아?”처럼 이전 대상을 가리키거나 의도가 모호한 입력은 자동 검증하지 않습니다.

## 실행 기록

- `node --test app/components/chat-intent.test.mjs` — 통과, 14개
- `npm run typecheck` — 통과
- `git diff --check` — 통과

## 미검증 범위

- 실제 의도 분류 API 장애 상황 및 실제 검증 제공자 호출은 확인하지 않았습니다.
- 브라우저 화면과 전체 빌드는 확인하지 않았습니다.
