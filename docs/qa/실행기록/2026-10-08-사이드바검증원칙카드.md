# 2026-10-08 [bsj] 사이드바 검증 원칙 안내 카드 제거

## 변경 내용
- 사이드바 하단의 검증 원칙 안내 카드와 연결 버튼을 제거했습니다.
- 카드에서만 사용하던 `.principle-card` 스타일을 제거했습니다.
- 별도 검증 원칙 메뉴는 유지했습니다.

## 실행 및 검증 기록
| 확인 | 결과 |
|---|---|
| JSX·CSS 참조 확인 | 변경 후 정적 검색에서 `principle-card` 참조가 없음을 확인했고, `검증 원칙` 메뉴와 `.sidebar-bottom`의 상태·푸터 표시는 유지됨을 확인했습니다. |
| 브라우저 시각 확인 | 미실행. 실제 사이드바 스크롤 길이는 화면에서 확인하지 못했습니다. |
| Git 상태·diff 확인 | `git status --short --branch`, `git diff --check`, `git diff --stat`, `git diff`를 실행하려 했으나 셸 프로세스 생성 단계에서 `helper_unknown_error: setup refresh had errors`로 실패하여 명령이 실행되지 않음 |

## 미검증 범위
- 브라우저에서 카드 제거 후 스크롤 길이가 줄었는지 시각적으로 확인하지 못했습니다.
- 셸 실행 오류로 전체 Git 상태와 diff를 확인하지 못해 커밋·푸시하지 않았습니다.
