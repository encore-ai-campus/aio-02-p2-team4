# 2026-10-08 [bsj] 저장 대화 제목 표시

범위: 사이드바의 긴 저장 대화 제목이 한 줄에서 잘려 구별하기 어려운 문제를 보완한다.

- 변경: 사용자 화면 피드백에 따라 두 줄 표시를 한 줄 말줄임으로 변경한다. 기존 `title` 속성을 유지해 마우스 오버 시 전체 제목을 표시한다.
- 삭제: 기존 삭제 확인창을 유지했으며 삭제 동작은 변경하지 않았다.
- 확인: 정적 코드 확인에서 한 줄 말줄임 규칙, 기존 전체 제목 `title` 속성, 삭제 확인창 유지를 확인했다.
- 미검증: 브라우저에서 실제 말줄임·마우스 오버 도움말 표시, 좁은 사이드바와 모바일 표시, 타입 검사·테스트·빌드.
- 실행 환경: `git status --short` 명령 실행은 도구 시작 단계에서 실패했다(`helper_unknown_error: setup refresh had errors`). 테스트나 빌드는 실행하지 않았다.
- 후속: 실행환경 복구 후 브라우저 화면 및 프로젝트 검증 명령을 확인한다.

## 2026-10-08 [bsj] 저장 대화 메뉴형 행 적용

- 변경: 저장 대화 목록을 프로젝트 메뉴처럼 왼쪽 선·두 자리 번호·한 줄 제목으로 표시하고 활성 항목을 밝게 강조한다. 제목에는 기존 `ScrambleText` 컴포넌트를 연결했다.
- 유지: 제목 말줄임과 버튼의 전체 제목 `title` 속성, 삭제 확인창, `+ 새 대화` 버튼의 기존 디자인을 유지했다. 워크스페이스·새 대화 시안은 구현에 반영하지 않았다.
- 정적 확인: Serena TypeScript 진단에서 오류가 반환되지 않았다. 변경 전 교체 범위의 dry run과 변경 후 관련 코드·스타일 검색으로 수정 위치를 확인했다.
- 검증 시도: `git status --short --branch`, `git diff --check`, `npm run typecheck`는 셸 프로세스가 시작되지 않아 실행되지 않았다(`helper_unknown_error: setup refresh had errors`).
- 미검증: 브라우저에서의 말줄임·전체 제목 툴팁·호버 스크램블 및 실제 레이아웃, 타입 검사, 빌드, Git diff/status.
- 후속: 실행 환경이 복구되면 브라우저 화면과 타입 검사를 확인하고 작업 브랜치에 커밋·푸시한다.
