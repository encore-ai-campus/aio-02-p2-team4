# 2026-10-13 [bsj] PR #9 병합 직전 버전 복구

> 이 문서는 과거 롤백 작업의 기록입니다. 이후 사용자 요청으로 최신 `main`을 `feat/frontend`에 다시 가져왔으며, 현재 상태는 [main 가져오기 실행 기록](2026-10-13-main-frontend-가져오기.md)을 따릅니다.

## 요청과 대상

사용자께서 사진에 표시된 PR #9 병합 완료 시점의 직전 `main` 버전을 선택하셨습니다. 대상은 `68157e0f0cfa42f29296c6d97d80930a84627dd8`이며, PR #9 병합 커밋 `b87f1da`의 첫 번째 부모와 일치합니다.

작업 시작 브랜치는 `feat/frontend`, 시작 커밋은 `58701a2`였으며 미커밋 변경은 없었습니다. 원격 조회 시 `origin/main`은 `a89395a`로, 요청 대상 이후 팀원 변경이 추가되어 있었습니다. 이 작업은 `feat/frontend`에서 이전 내용을 복구하고 새 커밋으로 기록합니다. `main`에 직접 push하거나 이력을 재작성하지 않습니다.

## 복구 범위

- 대상 커밋과 달랐던 추적 파일 25개를 Git 스냅샷에서 복구했습니다. 복구 직후 `git diff --exit-code 68157e0 --` 결과는 차이 없음이었습니다.
- 추가 YouTube 검색과 영상 자리 확보, 단일 주장 발광 해제, 전체 진행 단계 표시, 최근 원문 대기·경과 시간 수정, 이후 판정 지침 보완을 함께 취소했습니다.
- 대상에 이미 포함되어 있던 주장별 점수 버튼·출처 연결 강조·반투명 배경 등 기존 UI는 해당 시점 그대로 복구했습니다.
- 소스·테스트·설정·아키텍처는 요청한 버전 그대로이며, 작업현황과 이 실행 기록만 복구 사실을 알리기 위해 추가했습니다. 이전 변경은 Git 이력에서 다시 확인할 수 있습니다.
- 기존 경과 시간 표시 동작도 복원되므로 최근 수정의 완료 시간 고정 기능은 포함되지 않습니다.

## 실행과 결과

| 실행 항목 | 결과 |
|---|---|
| `git status --short --branch` | 작업 시작 시 `feat/frontend`, 변경 없음 |
| `git fetch origin` | 최신 원격 브랜치 조회 완료 |
| `git rev-parse b87f1da^1` | `68157e0f0cfa42f29296c6d97d80930a84627dd8` 확인 |

| `git restore --source=68157e0 --staged --worktree -- <확인한 25개 경로>` | 복구 완료. 저장소 내부 경로와 깨끗한 작업 트리를 확인한 뒤 실행 |
| `git diff --exit-code 68157e0 --` | 문서 기록 추가 전 전체 추적 파일 차이 없음 |
| `npm run typecheck` | 통과 |

빌드가 생성한 `next-env.d.ts`의 경로 변경은 확인 후 제외했습니다. 복구 기록 두 문서를 제외한 모든 추적 파일은 요청 대상과 동일한 상태로 커밋합니다. 일반 push를 사용하며, 완료 후 브랜치와 원격 커밋의 일치·작업 트리 상태를 확인합니다.

## 남은 범위

- 원격 `main`과 공개 배포는 아직 변경하지 않았습니다. `main` 반영은 저장소 지침에 따라 PR과 담당자 확인이 필요합니다.
