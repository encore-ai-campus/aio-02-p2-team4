# 2026-10-12 [bsj] 단일 주장 출처 강조와 별도 YouTube 검색

## 변경 사항

- 검증 주장이 하나일 때는 ‘검토한 출처’ 패널의 선택 주장 연결 발광 테두리를 표시하지 않습니다. 주장이 둘 이상이면 기존 선택 강조를 유지합니다.
- 각 고유 주장 검색어마다 YouTube 전용 검색을 별도로 실행합니다. Tavily 사용 시 `youtube.com`·`youtu.be` 도메인만 검색하며, 미설정·실패 시 모델 웹검색 경로에서 별도 검색합니다.
- 영상 URL로 확인되는 관련 YouTube 후보만 출처로 취급합니다. 관련 영상이 있으면 전체 6개 출처 한도 안에서 한 자리를 확보하고, 없으면 일반 출처만 표시합니다.
- YouTube 전용 검색 실패는 로그에 남기고 일반 검색 결과는 유지합니다. 링크 제목 보조 검색 등 명시적 추가 검색에서는 중복 YouTube 검색을 실행하지 않습니다.
- 외부 전송 동의 문구·개인정보 처리방침과 아키텍처 문서를 새 검색 흐름에 맞췄습니다.

## 미검증 항목

- 실 API 키로 관련 YouTube 영상이 반환되는지, 검색 결과의 품질과 실제 credit 사용량을 확인하지 않았습니다.
- YouTube 검색 추가 후 실제 응답 시간과 최대 출처 6개 유지 동작은 실환경에서 확인하지 않았습니다.
- 브라우저에서 단일 주장·복수 주장 발광 표시를 확인하지 않았습니다.

## 같은 날 main 병합 전 추가 검증

- 새 YouTube 검색 호출과 실제 지원되는 영상 URL에 맞게 기존 백엔드 테스트를 조정했습니다.
- Tavily의 도메인 제한 검색·제외 영상 URL·출처 6개 한도, YouTube 검색 실패 시 일반 출처 유지, 링크 제목 보조 검색에서 중복 조회하지 않는 동작을 추가 검증했습니다.
- 프런트엔드 133개·백엔드 473개 테스트, 타입 검사·프로덕션 빌드·의존성 잠금 검사를 통과했습니다. 앞선 ‘자동 테스트 실행하지 않음’은 최초 구현 당시 기록이며, 이번 병합 검증으로 보완되었습니다.
- 실 API 검색 품질·실제 응답 시간과 브라우저 시각 확인은 여전히 미실행입니다. [병합 실행 기록](2026-10-12-frontend-추가병합.md)을 참조하세요.
