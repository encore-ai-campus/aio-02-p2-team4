# 2026-10-08 [bsj] 검증 원칙 링크 위치 조정

## 변경 내용

- 페이지 하단의 직접 자식 검증 원칙 버튼에 오른쪽 여백 56px을 적용해 왼쪽으로 이동시켰습니다.
- 고정 배경 모션 버튼과의 겹침을 피하면서 다른 푸터 링크 배치는 유지했습니다.

## 실행 및 검증 기록

| 확인 | 결과 |
|---|---|
| Serena CSS 참조 확인 | `.page-footer > .text-button`에 `margin-right: 56px`이 설정되고, 모바일의 기존 자동 왼쪽 여백 규칙과 함께 적용됨을 확인함 |
| Git 상태·diff 확인 | `git status --short --branch`, `git diff --check`, `git diff --stat` 실행을 시도했으나 셸 프로세스 생성 단계에서 `helper_unknown_error: setup refresh had errors`로 실패하여 명령이 실행되지 않음 |
| 브라우저 시각 확인 | 미실행. 실제 화면에서 겹침 해소 여부는 확인하지 못함 |

## 미검증 범위

- 브라우저에서 실제 여백과 좁은 화면 푸터 줄바꿈을 시각적으로 확인하지 못했습니다.
- Git 상태와 diff를 확인하지 못해 커밋·푸시하지 않았습니다.
