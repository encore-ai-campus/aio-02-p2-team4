# 별도 합성 제거 검증 (2026-10-08)

## 요약

모든 메인 검증 입력에서 판정 이후 별도 합성 LLM을 제거했습니다. 판정·점수·원문 인용 검사·조건부 1회 재탐색을 유지하고, 주장별 요약·확인된 내용·불확실성·경고·근거 링크를 직접 표시합니다. 실제 지연 절감 시간은 미측정입니다.

## 변경 범위

- 합성 프롬프트·패킷·SDK 호출·미완료 재시도·공급자 폴백을 제거했습니다. `answer_synthesis.py`에는 빈 응답 표시 생성기만 남습니다.
- 새 응답 `judgment_only`는 생성 블록·합성 모델 메타데이터를 허용하지 않습니다. 기존 NDJSON `synthesizing` 이름은 호환용이며 화면에는 ‘정리’로 표시합니다.
- 복잡한 사실·긴 원문·링크·이미지·예측도 판정으로 종료합니다. 예측에 별도 종합 설명을 생성하지 않습니다. JEV 점수 화면과 명시적 모델 단독 사용 정책은 유지합니다.
- 과거 답변의 표시·대화 저장 및 복원을 유지합니다. 검증된 자막 근거는 링크로 연결하고, 기존 생성 답변의 유튜브 제한·불가 출처·위험 URL 차단을 유지합니다.

## 브라우저·실행 서버

- 시험 백엔드 8017과 Next production 3017을 사용했습니다. 의도·수집·판정은 모의 어댑터이며 최종화·결과 계약·NDJSON은 실제 런타임입니다. 외부 모델·DB를 호출하지 않았습니다.
- Chrome에서 일반 원문과 유튜브 자막 모두 완료 상태·‘정리’ 단계·90점·‘판정 결과’·확인된 내용·불확실성·정확한 출처 URL을 확인했습니다. [검증 화면](2026-10-08-합성제거.png)을 저장했습니다.
- 자막 최초 실행은 시험 데이터의 `youtubeDataStatus` 누락으로 프론트 계약이 거절했습니다. 실제 수집과 같은 `collected`·자막 표시로 수정하여 재실행을 통과했습니다. 제품 검증을 완화하지 않았습니다.
- 수정한 시험 서버의 최종 실행에서 intent·검증 각각 1회를 관찰했습니다. 모델 호출 수 검증은 위 모의 HTTP 테스트와 구분합니다.
- 사용자 8010 백엔드를 같은 설정으로 재시작하고 OpenAPI의 `judgment_only`를 확인했습니다. 기존 3000(PID 21528)은 유지했습니다. 시험 3017·8017 포트 및 검증 탭 종료를 확인했습니다.
