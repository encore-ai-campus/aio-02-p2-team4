# 2026-10-12 [bsj] 주장별 점수 팝오버·원문 패널 제거

## 변경 사항

- 주장이 2개 이상일 때만 점수 카드 오른쪽 위에 ‘주장별 점수’ 버튼을 표시합니다. 포인터를 올리거나 키보드로 포커스하면 목록이 열립니다. 버튼을 클릭하면 목록이 고정되고, 다시 클릭하면 고정이 풀리며 닫힙니다.
- 목록의 주장을 선택하면 해당 주장과 근거 패널이 기존처럼 바뀝니다.
- 목록이 고정된 상태에서는 주장을 선택해도 열린 상태를 유지합니다.
- 원문 패널과 모바일 ‘원문’ 탭을 제거했습니다. 모바일 탭은 ‘결과’와 ‘출처’만 표시합니다.
- 종합 점수 카드는 한 열 전체 너비로 사용합니다.

## 실행 및 결과

| 실행 항목 | 결과 |
|---|---|
| `npm run typecheck` | 통과 |
| `npm run build` | Next.js 16.3.5 프로덕션 빌드 통과 |
| `git diff --check` | 통과 |
| 제거된 원문·기존 주장 카드 선택자 검색 | 관련 코드 참조 없음 |

## 미검증 항목

- 브라우저에서 버튼의 실제 위치·팝오버 배치와 hover·키보드·터치 동작을 확인하지 않았습니다.
- 실제 1개 주장과 여러 주장 결과를 화면에서 비교하지 않았습니다.
- 자동 테스트는 실행하지 않았습니다.

## 작업 환경 메모

- 빌드가 생성한 `next-env.d.ts` 변경은 빌드 전 상태로 복구했습니다.
- 기존 `graphify-out/` 변경은 이번 작업 범위가 아니므로 수정하거나 커밋하지 않았습니다.

## 후속 변경: 클릭 시 목록 고정

- ‘주장별 점수’ 버튼을 클릭하면 목록이 계속 열려 있고, 버튼을 다시 누르면 닫히도록 했습니다. 고정 상태에서는 포인터를 옮기거나 목록에서 주장을 선택해도 열린 상태를 유지합니다.
- `npm run typecheck`: 통과
- `npm run build`: Next.js 16.3.5 프로덕션 빌드 통과
- `git diff --check`: 통과
- 브라우저에서 클릭·키보드·터치 동작은 확인하지 않았습니다.

## 후속 변경: 고정 상태와 주장별 판정 표기

- 목록을 고정했을 때 ‘주장별 점수’ 버튼에 민트색 테두리와 글로우를 표시하고, 토글 상태를 `aria-pressed`로 제공합니다.
- 각 주장 행의 배지 앞에 ‘판정’을 붙여 ‘대체적으로 거짓’ 등의 판정이 어떤 주장에 해당하는지 구분합니다.
- `npm run typecheck`: 통과
- `npm run build`: Next.js 16.3.5 프로덕션 빌드 통과
- `git diff --check`: 통과
- 실제 브라우저 화면에서 글로우와 모바일 배치는 확인하지 않았습니다.
