# 2026-10-08 [bsj] 팩트 점수 기준 버튼 위치 보정

## 변경 내용

- 점수 기준 버튼을 주장별 결과 영역에서 제거하고 `종합 신뢰지수` 카드 헤더 오른쪽에 배치했습니다.
- 기준표가 카드 헤더 아래로 열리도록 조정하고, 평균 점수에 해당하는 구간을 강조합니다.

## 실행 및 검증 기록

| 확인 | 결과 |
|---|---|
| Serena JSX 정적 확인 | `FactScoreGuide`가 종합 신뢰지수 헤더에 있고 주장별 점수 영역에는 없는 것을 확인함 |
| Serena 컴포넌트 진단 | 변경 영역에서 오류·경고가 보고되지 않음 |
| Serena CSS 정적 확인 | 헤더 우측 정렬, 세로 중앙 정렬, 헤더 아래 팝오버 배치와 카드 너비 제한 규칙을 확인함 |
| `git status --short --branch` 및 `git diff --check` | 실행을 시도했으나 프로세스 생성 실패: `helper_unknown_error: setup refresh had errors` |
| 브라우저·빌드 확인 | 미실행. 실제 화면에서 좌표와 팝오버 잘림 여부는 미검증 |

## 미검증 범위

- 브라우저에서 버튼이 제공된 이미지의 위치에 맞는지 직접 확인하지 못했습니다.
- Git 상태·diff를 확인하지 못해 커밋·푸시하지 않았습니다.
