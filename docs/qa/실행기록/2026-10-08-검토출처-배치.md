# 검토 출처 패널 배치

- 요청: 검토한 출처 패널을 왼쪽 상단의 빈 공간에 배치
- 변경: 데스크톱에서 원문 패널 아래 왼쪽 열에 출처 패널을 배치하고, 선택한 주장과 근거 패널은 두 행 높이를 차지하도록 조정
- 표시: 데스크톱 출처 카드는 한 열로 표시하며 모바일의 기존 탭·세로 레이아웃은 유지
- 확인: 변경한 CSS 규칙을 확인함. 전체 작업 트리의 `git diff --check`는 기존 `app/components/fact-check-dashboard.tsx:517`의 공백 경고를 표시함
- 미검증: 테스트, 빌드, 브라우저 시각 확인은 실행하지 않음
