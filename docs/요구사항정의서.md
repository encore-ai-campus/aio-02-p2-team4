# TRUE OR NOT 요구사항 정의서

기준일: 2026-10-15. 현행 코드와 확인된 실행 기록 기준. 정책은 [기획서](기획서.md), 구조는 [아키텍처](아키텍처.md), 잔여·미결정은 [작업현황](작업현황.md)와 [Agent 기록](agent/agent_작업현황.md)을 따른다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 시스템 이름 | TRUE OR NOT |
| 목적 (한 문장) | 사용자가 보낸 주장·원문에 대해 근거를 추적·비교한 검증 결과를 보여준다 |
| 사용자 | 온라인 주장에 의문을 가진 일반 사용자 |
| 이해관계자 | 프로젝트 팀원 (4명: 프론트·검증엔진·검색/배포·계약/QA), 시연 심사자 |

## 2. 시스템 범위

| 구분 | 내용 |
|---|---|
| 포함 | 텍스트·링크·이미지 검증, 주장별 판정·근거, 공유 비밀번호 접속, 대화 저장·복원·삭제·만료 정리, 데모·내보내기 |
| 제외 | 개인 계정·기기 동기화·공유, 얼굴·개인정보 분석, 의학·법률·투자 판단, 장기 기억 요약·벡터 검색 |

## 3. 기능 요구사항

| ID | 요구사항 | 설명 | 우선순위 |
|---|---|---|---|
| REQ-01 | 주장 추출 | 입력에서 최대 3개 주장 추출, 원문 위치 연결. 후보 선택 없이 자동 실행 | 필수 |
| REQ-02 | 외부 전송 동의 | 첫 외부 호출 전 1회 동의. 거절 시 외부 호출 없이 입력 보존 | 필수 |
| REQ-03 | 검색·원문 수집 | Tavily 우선·LLM 대체. 출처 최대 6개·4건 병렬 읽기. 조건부 Playwright·Tavily Extract 복구 | 필수 |
| REQ-04 | 주장별 판정 | 7종 판정. LLM 제안 후 인용·참조 무결성 코드 검증 | 필수 |
| REQ-05 | 최종 결과 정리 | 추가 합성 LLM 없이 `judgment_only` 판정·확인 내용·불확실성·인용 표시. 과거 생성 답변 읽기 호환 유지 | 필수 |
| REQ-06 | 재탐색 | 인용 탈락 또는 접근 불가 엄격 과반일 때만 최대 1회 | 필수 |
| REQ-07 | JEV 빠른 경로 | 점수 전용 판정. 이미지 거부 | 선택 |
| REQ-08 | 내용 요약 | 판정 없는 요약. 이미지 요약 제외 | 선택 |
| REQ-09 | 대화 저장 | 기본 꺼짐·익명 쿠키 소유권. 동의한 대화 저장·복원·삭제, 신규 대화는 30일 세션 만료 시각을 보관 기한으로 사용. 시작 시·매시간 만료 정리 | 필수 |
| REQ-10 | 진행·취소 | NDJSON 진행 표시, 취소 전파, 늦은 응답 무시 | 필수 |
| REQ-11 | 데모·내보내기 | 합성 예시 구분, 결과 JSON 다운로드 | 필수 |

## 4. 비기능 요구사항

| ID | 항목 | 기준 |
|---|---|---|
| NFR-01 | 응답 시간 | 전체 경과와 검색·읽기 소요 시간을 구분. 과거 합성 포함 관측값을 현재 응답 성능으로 제시하지 않음 |
| NFR-02 | 동시성 | 메인 검증 10건, DB 풀 4개·작업 3초 |
| NFR-03 | 보안 | 키는 서버 환경에만. 비밀값 로그·커밋 금지 |
| NFR-04 | 품질 게이트 | 머지 전 BE·FE 테스트·타입 통과 |
| NFR-05 | 표현 원칙 | 미측정 정확도 수치 홍보 금지. 근거 부족·생성 실패 구분 표시 |

## 5. 제약사항·가정

- Vercel 프런트·프록시와 Render FastAPI·PostgreSQL로 배포한다. 서비스·DB 리소스 설정은 [배포 문서](배포.md)를 따른다.
- 앱의 30일 세션 보관 정책과 과거 무료 DB 인스턴스의 만료는 별개다. 만료 정리는 서버·DB가 정상 가동 중일 때 최대 1시간 지연되며 중단 후에는 재시도한다.
- 외부 공급자(모델·검색·시세)의 권한·요금·장애는 서비스가 통제하지 않는다.
