### 토큰 재시도 모의 재현

다음 코드는 backend 작업 디렉터리에서 기존 가상환경으로 실행합니다. 모든 HTTP는 MockTransport로 대체하고 테스트용 값만 사용합니다. 키·헤더·원문 payload를 출력하지 않습니다.

```python
import asyncio
import json
from unittest.mock import patch
import httpx
from pydantic import SecretStr
import runtime

payloads = []
real_client = httpx.AsyncClient

def respond(request):
    payloads.append(json.loads(request.content))
    return httpx.Response(200, json={
        "choices": [{"finish_reason": "length", "message": {"content": None}}]
    })

def offline_client(*args, **kwargs):
    kwargs["transport"] = httpx.MockTransport(respond)
    return real_client(*args, **kwargs)

async def probe():
    adapters = runtime.make_runtime_adapters(runtime.Settings(
        api_key=SecretStr(""), explabs_api_key=SecretStr("mock-only")
    ))
    state = {
        "modelPreference": "deepseek-v4.1-flash",
        "sources": [{"id": "s1", "url": "https://example.org/source",
                     "title": "Example", "publisher": "example.org",
                     "accessStatus": "verified", "sourceType": "article"}],
        "sourceTexts": {"s1": "The source supports this claim."},
    }
    with patch("runtime.httpx.AsyncClient", side_effect=offline_client):
        try:
            await adapters.synthesize(state)
        except ValueError as exc:
            assert str(exc) == "MODEL_FAILED"
            return
    raise AssertionError("Expected synthesis failure")

asyncio.run(probe())
assert len(payloads) == 2 and payloads[0] == payloads[1]
assert [item["max_tokens"] for item in payloads] == [16000, 16000]
print("2 calls; identical payloads; max_tokens=[16000,16000]; MODEL_FAILED")
```

## 확인한 범위와 남은 작업

- `synthesis_failed`는 백엔드 계약·프론트 타입·클라이언트 검사·화면에 연결되어 있습니다. 단일 모델의 합성 실패 시 검증된 주장·근거를 유지하는 회귀를 확인했습니다.
- 실제 지연·비용·완료율과 변경 후 실제 공급자 성공은 미측정입니다. 테스트 통과를 속도 개선의 증거로 취급하지 않습니다.
- 수정은 적용하지 않았습니다. 담당자가 두 발견과 수정 방향을 확인하고 실제 요청 상한·재탐색 경계 테스트를 추가해야 합니다.
- 임시 웹서버·브라우저는 실행하지 않았습니다. 테스트와 모의 재현 프로세스는 종료했고 기존 사용자 서버는 조작하지 않았습니다.
