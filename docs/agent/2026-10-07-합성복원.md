# 2026-10-07 합성 복원·재탐색 조이기

범위: 합성 실패 graceful 처리 3건과 재탐색 발동 조이기. `feat/agent` 작업, 리뷰 2건(동일 페이로드 재시도·절반 경계) 반영 완료.

- 단일 모델 합성 실패도 판정 유지 + `synthesis_failed` 상태로 결과 반환한다. 전체 실패가 아니다.
