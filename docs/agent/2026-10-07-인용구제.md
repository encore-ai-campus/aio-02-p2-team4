# 2026-10-07 인용 구제

합성 검증이 인용 하나 삐끗으로 답변 통째로 버리던 문제를 고쳤다.

- 공백·따옴표 차이 인용은 원문의 실제 구간으로 교정하고, 완전히 딴 인용만 제거한다. 교정된 인용도 원문의 정확한 부분 문자열이라 원칙 유지.
- 인용 잃은 항목·섹션은 잘라내고, 개요·결론에 인용 남으면 답변 채택. 둘 중 하나라도 비면 기존대로 거부.
- 실행: BE 495개·FE 107개·타입 통과.
- 리뷰 반영: `…`·`⋯`를 정규화한 각 문자에 원문 위치를 매핑하여 인용 구간과 부정어를 보존합니다. 교정 인용을 기존 계약으로 다시 검증하고, 2,000자를 넘는 인용만 제거합니다.
- 재검증: 새 회귀 9개와 전체 백엔드 504개가 통과했습니다. 모의 HTTP에서 정상 개요·결론 유지와 첫 공급자 호출 1회를 확인했습니다. 프론트엔드 검증 및 실제 LLM 지연 측정은 이번 수정에서 재실행하지 않았습니다. 명령·결과는 [Agent 작업현황](agent%20작업현황.md)을 따릅니다.
