## 결정 사항

확정된 모델 설정과 Render 플랫폼 선택은 기획서·아키텍처에 반영되어 있다. 일부 확정된 안건은 같은 D 번호로 확정 내용과 남은 결정을 나누어 표시한다. 확정은 정책 선택을 의미하며 구현·실환경 검증 완료 여부는 각 행의 명시 상태와 완료 목록을 따른다. 미결정 표의 추천안은 사용자·팀 결정 전까지 코드 변경의 확정 정책이 아니다. 무응답이나 일정 경과로 자동 확정하지 않는다.
