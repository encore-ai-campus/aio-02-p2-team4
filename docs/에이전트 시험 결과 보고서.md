## 1. 시험 목적

 자기 성찰 루프(재탐색) 적용 전후의 도구 선택 정확도, 태스크 완료율, 응답 일관성, 평균 재시행 횟수를 동일한 시험 데이터로 비교합니다.

 이 프로젝트의 자기 성찰은 재탐색 루프입니다. 판정이 "근거 부족"이고 원인이 출처 수집 실패나 인용 거부이면 검색어를 바꿔 1회 다시 찾습니다. 비교는 두 방법으로 했고, ②의 실측을 주 결과로 씁니다.

| 비교 방법 | 데이터 | 상태 |
| --- | --- | --- |
| ① 반사실 재집계 (보조) | 정규 625회차에서 재탐색 회차를 성찰 전 판정(근거 부족)으로 되돌려 같은 산식으로 계산 | 완료 (추정값) |
| ② 끔/켬 통제 실험 (주 결과) | 같은 버전에서 `TON_RECOVERY=off`(끔) / 기본값(켬), 과학·건강, 역사·지리·상식 35문항 × 2회 = 70회차씩 진행 | 완료 (실측) |

## 2. 시험 데이터 구성

시험은 정답 원장 영역, 장애·입력 오류는 오프라인·화면 자동 테스트로 확인했습니다.

| 양식 유형 | 이 프로젝트 대응 유형 | 건수 | 확인 항목 |
| --- | --- | --- | --- |
| 정상 요청 | 5가지 도메인의 참·거짓·부분·조건 생략·출처 간 이견 주장 | 74문항 × 5 = 370회차 | 허용 판정(확인·반박·일부 확인 등) |
| 정상 요청 (판정 금지) | 의견·예측·전달 발화 (기대: 검증 대상 아님) | 12문항 × 5 = 60회차 | 사실로 판정하지 않음 |
| 공통 일정 없음 | 근거 부재·속설·개인 판단 요청 (기대: 근거 부족) | 6문항 × 5 = 30회차 | 추측 없이 "근거 부족" |
| 공통 일정 없음  | 검색 4건·읽을 원문 없음 | 4건 | 모델 미호출·결론 유보 |
| 필수 파라미터 누락 | 빈 입력·동의 없음·12,000자 초과·이미지 형식/8MB 초과·비공개 URL(SSRF) | 화면 2건 + 오프라인 22건 | 그래프 실행 전 거부·안내 |
| API 타임아웃 | 공급자 시간 초과·HTTP 오류·스트림 240초·취소 | 오프라인 12건 + 실측 관측 | 공급자 폴백, 안전한 오류, 취소 전파 |
| 인증 실패 | LLM·외부 데이터 API 401/403, 공급자 키 없음 | 오프라인 2건 (TC-131·132) | 상세 미노출 오류, 안전한 중단 |
| 상충 지시 | 프롬프트 인젝션(판정 강요·역할 탈취·프롬프트 유출·내부 주소 유도) + S11 이미지 속 지시 | 7문항 × 5 = 35회차 | 지시 불이행·유출 없음 |
| 계산 | 단순 산수 | 6문항 × 5 = 30회차 | 계산 판정 |
| 표현 변형 | 같은 사실 다른 문장·구어체 | 5문항 × 5 = 25회차 | 기준 문항과 같은 판정 |
| 대화 | 인사·감사 | 2문항 × 5 = 10회차 | 검증 미호출 |
| 링크 입력 | 위키백과 링크 첨부 | 7문항 × 5 = 35회차 | 링크 우선 출처 |
| 이미지 입력 | SNS·메신저·뉴스 카드 캡처 (인젝션 1문항은 상충 지시에 포함) | 6문항 × 5 = 30회차 | 텍스트와 같은 판정 |
| **합계 (실공급자)** |  | **125문항 × 5 = 625회차** |  |

**순서도 ① 전체 처리 흐름 — 영역별 단계**

한 요청이 위에서 아래로 6개 영역을 지나갑니다. 왼쪽 띠 이름이 영역(수행 주체)이고 영역 안에서는 왼쪽에서 오른쪽으로 진행합니다. 굵은 실선이 정상 경로, 파란 점선이 자기 성찰(재탐색) 경로입니다.

!image.png

| 영역 | 하는 일 | 다음으로 가는 조건 |
| --- | --- | --- |
| 1 입력 검사 | 동의·글자 수(12,000자)·이미지(8MB)·공개 URL 확인 | 위반이면 입력 거부 안내로 끝남 |
| 2 의도 판별 | LLM이 검증 요청(verify)인지 대화(reply)인지 분류 | reply면 대화 응답으로 끝남 |
| 3 검증 그래프 | 추출 → 검색(Tavily 실패 시 모델 내장 검색) → 읽기 → 검증(LLM 판정 제안) | 항상 검증기로 |
| 4 검증기 | 인용·스키마 검사(위반 인용 제거), 근거 부족의 원인이 수집·인용 실패인지 확인 | 원인이 맞고 아직 재탐색 전이면 5로, 아니면 6으로 |
| 5 자기 성찰 | 검색어를`공식 원문 …`으로 바꾸고 실패 출처를 빼서 검색 → 읽기 → 검증 재실행 | 다시 4 검증기로 (최대 1회) |
| 6 결과 표시 | 근거가 있으면 판정 표시, 재탐색 후에도 없으면 근거 부족 유지 + 제한사항 안내 | 끝 |

**순서도 ② 오류 감지 → 원인 분석 → 수정 전략 → 재실행 → 검증**

순서도 ①의 4번(검증기)에서 문제가 감지됐을 때를 발생하는 프로세스입니다. 

세로 열이 양식의 5단계(① 오류 감지 → ② 원인 분석 → ③ 수정 전략 선택 → ④ 재실행 → ⑤ 검증)이고 가로 줄 하나가 오류 유형입니다. 

왼쪽 **시작** 노드에서 들어와 오른쪽 **종료** 노드(초록·빨강)로 끝나며,재실행이 있는 두 유형(공급자 오류·근거 확보 실패)은 **아래쪽 파란 점선 피드백 고리**를 따라 재실행 결과를 감지부터 다시 검사합니다. 통과하면 결과 표시, 남은 기회(공급자 폴백은 남은 공급자 수, 재탐색은 1회)가 소진되면 빨간 종료 노드로 끝납니다.

!image.png

| 단계 | 수행 주체 | 입력 → 출력 | 종료·폴백 |
| --- | --- | --- | --- |
| ① 오류 감지 | 검증기 | 모델 판정 제안 → 위반 목록 | 위반 없으면 ⑤로 |
| ② 원인 분석 | 검증기 | 위반·진단 코드 → 오류 유형(인용 위반 / 공급자 오류 / 근거 확보 실패) | 규칙 분류만 |
| ③ 수정 전략 선택 | 검증기 | 오류 유형 → 4개 전략 중 하나 | 전략 4(240초)는 즉시 종료 |
| ④ 재실행 | 검색·읽기 → LLM 공급자 | 바뀐 검색어·제외 출처 → 새 원문 → 새 판정 제안 | 재탐색 최대 1회, 폴백은 공급자 수만큼 |
| ⑤ 검증 | 검증기 | 새 판정 → 통과(grounded) / 실패 | 재탐색을 이미 1회 했으면 unresolved로 종료 |

- 대신 판정을 그대로 보여 주면서 드러난 문제를 **재이슈화**:
    - 복합 주장("세종대왕은 한글과 측우기를 발명했다")에서 틀린 부분이 판정에서 빠지는 문제 → 정규에서 최우선 결함으로 등록, 해결 방안은 5.2
    - 판정이 "근거 부족"으로 강등돼도 모델 점수(68점)가 그대로 남는 문제

### 5.2 복합 주장 오류 해결 방안

**문제**

한 문장에 사실이 둘 이상 들어 있으면 추출 단계가 문장을 조각으로 나누는데 이때 틀린 요소가 든 조각이 빠지거나 판정되지 않습니다. 

| 문항 (기대 판정) | 회차 | 판정된 조각 → 결과 | 빠진 요소 |
| --- | --- | --- | --- |
| 제21대 대선 김문수 당선 (반박) | 5/5 | 〈2025년 6월 3일 치러진 제21대 대통령 선거〉만 확인, 종합 49~58점 | 당선자 |
| 22대 총선 날짜 + 투표율 90% (일부만) | 5/5 | 선거일만 확인, 종합 44~54점 | 투표율 수치 |
| 이순신 한산도 + 행주 대첩 (일부만) | 4/5 | 한산도만 확인, 종합 50~53점 | 두 번째 사실 |
| 아폴로 11호 1969년 화성 착륙 (반박) | 2/5 | 〈아폴로 11호는 1969년에〉만 확인, 종합 48·49점 | 장소(화성) |
| 세종 한글 + 측우기 발명 (일부만) | 4/5 | 〈세종대왕은 한글〉만 판정 (재탐색 후 쪼개진 회차 포함) | 두 번째 사실 |

**원인 분석**

1. **추출**: 조각을 나눌 때 원문의 핵심 요소(고유명사·숫자·날짜·장소·부정어)가 조각 어딘가에 모두 남았는지 검사하지 않습니다. 조각이 원문의 일부이기만 하면 통과합니다(§3 감지 기준의 한계 표).
2. **검증**: 조각마다 판정을 1회 내도록 검사하지만, 원문 대비 빠진 요소는 조각 자체가 없으므로 검사 대상이 아닙니다.
3. **종합**: 조각 판정을 합칠 때 참 조각의 점수가 종합에 그대로 반영되어, 반박 조각이 있어도 중립(40~59점)으로 수렴합니다.
4. **재탐색**: 재탐색 후 다시 판정할 때 같은 문장이 다르게 쪼개지는 회차가 있습니다(AI-D3-04-R4·R5, §6.2 통과→미통과 7회 중 2회).
