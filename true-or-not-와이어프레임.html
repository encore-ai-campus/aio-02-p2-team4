화면·기능 전달 메모

화면 목록과 이동 흐름

  1. 01 원문 입력 — 새 대화와 입력 수단을 제공합니다.
  2. 02 대화 진행 — 원문과 에이전트 답변을 확인합니다.
  3. 03 주장 선택 — 원문에서 추출한 최대 3개 주장을 고르고 연결 근거를 확인합니다.
  4. 04 대시보드 빈 상태 — 아직 결과가 없을 때 시작 안내를 보여줍니다.
  5. 05 검증 결과 — 평균 팩트 점수, 주장별 점수, 출처와 연결 근거를 확인합니다.

기본 경로는 01 → 02 → 03 → 05이며, 대시보드에 결과가 없으면 04를 표시합니다. 보조 상태로 저장 대화 없음 안내, 답변 생성 중 진행 메시지, 답변을 유지하는 저장 오류와 재시도 안내를 포함합니다.
