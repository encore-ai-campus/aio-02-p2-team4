# Q: 원문 재검증 요청을 반복하는 원인

## Answer

확인 결과, 이전 자료가 없는 상태에서 의도 분류가 재검증 대상을 previous로 선택하면 backend/intent.py가 context.previousText만 검사해 항상 동일한 clarify 문구로 바꾼다. 이 검사에는 현재 입력의 text, image, link_url이 포함되지 않는다. 프런트엔드는 clarify 응답을 매번 addMessage/saveChat으로 추가하며 반복 응답을 억제하지 않는다. 따라서 새 원문을 보내도 previous로 잘못 분류되거나 활성 이전 결과가 없는 대화에서는 같은 요청이 누적될 수 있다. 개선하려면 이전 자료가 없어도 현재 입력에 검증 자료가 있으면 current 대상으로 처리하고, 자료가 실제로 없을 때만 한 번 확인해야 한다.
